# Nano Route — Message Highlight Policy
**Step 82 — Authoritative Highlight Specification**

## 1. Visual Presentation & Accessibility
- Highlights and bookmarks surface an accessible visual badge and filled icon state in the message header.
- Status is communicated via ARIA attributes (`aria-label="Bookmark message" / "Remove bookmark"`) and high-contrast color accents (`var(--nr-accent-amber)`), ensuring non-color-dependent perception.
