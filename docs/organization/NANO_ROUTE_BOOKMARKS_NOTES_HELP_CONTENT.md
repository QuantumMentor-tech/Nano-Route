# Nano Route — Bookmarks & Notes User Guide & Help Center
**Step 82 — Authoritative Help Reference**

## Overview
Nano Route lets you bookmark key answers, highlight crucial information, and attach private personal notes to any conversation turn.

## Features
1. **Bookmarking Messages**: Click the bookmark icon in any message footer to save it for quick reference.
2. **Private Notes**: Add personal annotations and reminders to message turns. Notes remain 100% private on your machine and are never shared with AI providers.
3. **Anchor Navigation**: Jump directly from saved bookmarks back to the exact conversational point.
