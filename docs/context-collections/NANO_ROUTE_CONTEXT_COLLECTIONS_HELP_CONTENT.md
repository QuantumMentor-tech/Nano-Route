# Nano Route — Context Collections & Reference Packs User Guide

## What Are Context Collections?
Context Collections (or Reference Packs) let you curate past conversation turns, excerpts, private notes, and attachment contexts into reusable packs. Instead of copying and pasting earlier responses, you can assemble relevant references into a pack and insert them into your message prompt with a single click.

## How to Add References
1. **From Any Assistant Message:** Click the **Collect** button in the message action row. Choose an existing collection or create a new one on the fly.
2. **From Private Notes:** In your notes panel, click **Add to Collection**. Note that adding a private note to a collection means its text will be included in the prompt sent to the AI model when that collection is inserted.

## Managing Collections
- Open the **Collections** modal by clicking the `Collections` button in the chat composer.
- Preview the exact text that will be sent, along with an estimated token count.
- Reorder items using the Up/Down arrow buttons.
- Delete unwanted items without affecting your original chat history.

## What Happens When Sources Change or Are Deleted?
If an underlying message or attachment is deleted from your chat history, the reference in your collection will be marked with a red **STALE** badge. The collection will never crash or silently drop the item, allowing you to review or remove it at your convenience.
