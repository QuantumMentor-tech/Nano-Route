# Nano Route — Message Rendering User Guide & Help Center
**Step 80 — Authoritative Help Reference**

## Overview
Nano Route provides a clear, high-contrast, and safe markdown rendering experience for all assistant answers and prompt turns.

## Features
1. **Safe Formatting**: Headings, lists, bold/italic accents, and blockquotes render cleanly without unsafe HTML execution.
2. **Code Blocks**:
   - Monospace typography with language labels.
   - Click **Copy** on any code snippet header to copy the raw code directly.
   - Long code blocks (over 25 lines) include an **Expand / Collapse** button to keep your conversation tidy.
3. **Message Copying**:
   - Click the **Copy** button on any assistant message header to copy the complete response text.
4. **Streaming Resilience**:
   - Incomplete code blocks or paragraphs stream into view smoothly without layout flickering.
