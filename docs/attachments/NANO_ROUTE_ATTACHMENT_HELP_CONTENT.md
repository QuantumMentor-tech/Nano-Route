# Nano Route — Local Attachments User Guide & Help Center
**Step 79 — Authoritative Help Reference**

## Overview
Nano Route allows you to attach local documents, code files, data tables, and images directly to your prompt compositions in Chat Studio.

## How to Attach Files
1. Click the **Attach** paperclip button in the Composer toolbar.
2. Select up to 5 files from your local system.
3. Supported formats include text files (`.txt`, `.md`), structured data (`.json`, `.csv`), code files (`.py`, `.ts`, `.rs`, `.html`, etc.), and images (`.png`, `.jpg`, `.webp`).
4. Attached files appear as removable chips above the prompt box with their name and size.
5. Click the **X** button on any chip to remove an attachment prior to sending.

## Security & Privacy
- Files are parsed entirely on your local machine; nothing is uploaded until you click Send.
- Executables, scripts (`.exe`, `.bat`, `.cmd`), and files exceeding 2 MB are blocked automatically for your safety.
