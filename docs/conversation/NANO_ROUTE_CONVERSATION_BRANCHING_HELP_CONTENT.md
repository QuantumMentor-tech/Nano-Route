# Nano Route — Conversation Branching User Guide & Help Center
**Step 81 — Authoritative Help Reference**

## Overview
Nano Route allows you to explore multiple directions in a chat without losing prior answers.

## Features
1. **Response Variants**: When an answer is regenerated, previous answers are kept safely. You can toggle between them using the `< 1 / N >` switcher on the message bubble.
2. **Conversation Branching**:
   - Create alternative branches from any message turn.
   - Continue a conversation along different reasoning paths without overwriting your original thread.
3. **Non-Destructive Guarantee**: Alternate responses never delete past messages.
