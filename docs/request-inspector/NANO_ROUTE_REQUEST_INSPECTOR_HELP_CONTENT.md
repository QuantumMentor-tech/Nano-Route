# Nano Route — Request Inspector & Final Review User Guide

## What is the Request Inspector?
The Request Inspector lets you see the exact, complete prompt that will be sent to the AI provider before any data leaves your computer. It breaks down your prompt, attached files, reference packs, estimated token counts, and cost impacts.

## When Should I Use It?
- **Before Sending Long Prompts:** Check whether your prompt fits comfortably within the model's context window.
- **When Using Context Collections:** Confirm which previous messages and notes are included in the prompt.
- **When Attaching Multiple Files:** Verify file sizes, categories, and estimated token requirements.
- **When Managing Budgets:** Review estimated request costs against your monthly budget limit.

## How to Open the Inspector
In the chat composer, type your message, add any files or collections, and click the **Inspect** button (shield icon) next to the Send button.

## What Happens When I Click "Send Request"?
Clicking "Send Request" inside the inspector performs a fresh pre-submit validation check. If everything is verified, it submits your prompt directly to Nano Route's intelligent routing engine. If your prompt changed while you were inspecting it, you will be prompted to review the updated preview first.
